# Gemini Launcher
The Main Launcher For The Gemini Discord Server

Windows launcher for the Gemini Season Two Project Zomboid (Build 42) server, built with [Tauri 2](https://tauri.app).

Players download the latest installer from [Releases](https://github.com/RobertWasteLand/Gemini-Launcher/releases/latest). After that the launcher updates itself.

## Naming convention

Everything we name follows `GL_<Name>_<Extra>`: `GL` for Gemini Launcher, then one word (or number) for what it is, then at most one more word to narrow it down. Examples: `GL_Steam_Find`, `GL_Game_Spawn`, `GL_Update_Run`, `GL_Notes_Text`, `GL_Play`. This covers files, functions, types, constants, commands, events, element ids, CSS classes and variables. Struct fields and local variables keep plain names. Names fixed by the tools stay as they are: `index.html`, `main.rs`, `build.rs`, `Cargo.toml`, `package.json` (npm only allows lowercase, so it is `gl_launcher`), `tauri.conf.json`, the `src` and `src-tauri` folders, the files in `src-tauri/icons` (regenerated by `npx tauri icon` when the art lands), and the `TAURI_SIGNING_*` secret names.

## Layout

- `src/` — the launcher window: `index.html`, `GL_Main.js`, `GL_Style.css`. Placeholder look until the art lands.
- `src-tauri/src/` — the Rust side: `GL_Steam.rs` (finds Steam and Project Zomboid), `GL_Process.rs` (starts Steam and the game), `GL_Update.rs` (self-update), `GL_Options.rs` (the toggles in the Options panel and the launch arguments each one adds), `GL_Config.rs` (player settings), `GL_Vdf.rs` (reads Steam's files), `GL_Tests.rs`.
- `GL_Live/GL_Notes.txt` — the patch notes every launcher shows. Edit and push; launchers pick it up within about 5 minutes, no new release needed.
- `.github/workflows/GL_Build.yml` — test build on every push to `main`; download it from the run's artifacts.
- `.github/workflows/GL_Release.yml` — publishes a new version that every launcher updates to.

## Releasing a new version

1. Raise `"version"` in `src-tauri/tauri.conf.json` (for example `1.0.0` → `1.0.1`). This is the only place the version lives.
2. Update `GL_Live/GL_Notes.txt` if the notes should change.
3. Commit and push.
4. On GitHub: **Actions → GL_Release → Run workflow**.

When it finishes, the new version is on the Releases page and every launcher installs it the next time it opens.

The release needs two repository secrets (**Settings → Secrets and variables → Actions**): `TAURI_SIGNING_PRIVATE_KEY` and `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`. They sign each update so launchers only accept updates from us. Keep a backup of both: if they are lost, installed launchers can no longer update and everyone has to reinstall by hand.

## Building locally

Needs [Node.js](https://nodejs.org) 22+, [Rust](https://rustup.rs) and the Microsoft C++ Build Tools.

```
npm install
npm run dev
npx tauri build --config src-tauri/GL_Build.json
```

The build writes the installer to `src-tauri/target/release/bundle/nsis/`. Dev builds never update themselves.

Player settings are saved in `%APPDATA%\com.robertwasteland.geminilauncher\settings.json`.

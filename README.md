# Gemini

This Launcher Is For Use Specifically For Gemini Season Two And Utilizes ZombieBuddy!

## Download

Get the latest installer from [Releases](https://github.com/RobertWasteLand/Gemini-Launcher/releases/latest). After that, the launcher offers each update when you open it.

Discord: https://discord.gg/dZTkKRxcbr
